# Investidor — Dicas e Carteiras Recomendadas

## O que tem aqui

Um arquivo, `dicas.ts`, com:

- **Dicas por classe de ativo** (ações, FIIs, renda fixa, etc.), incluindo teses de investimento
- **Carteiras recomendadas** que aparecem na tela do Investidor
- **Relatório da semana** — texto de análise mostrado na tela

## Como editar

Abra `dicas.ts` e edite os textos diretamente, seguindo a estrutura já existente para cada seção.

## Onde isso é usado no app

- `src/pages/InvestidorPage.tsx` — tela principal
- `src/pages/BuscaPage.tsx` — resultado de busca por carteiras recomendadas

# Glossário — Termos Financeiros

## O que tem aqui

Um único arquivo, `termos.ts`, com a lista de termos do glossário do app.

## Como adicionar um termo novo

Abra `termos.ts` e siga as instruções do comentário no topo do arquivo. Resumindo: copie uma linha existente, cole no final, preencha `termo`, `def` e `modulo`.

O campo `modulo` precisa ser exatamente igual ao título de um módulo existente em `banco-de-dados/modulos/`, para o app conseguir linkar o termo ao módulo certo na tela.

## Quantidade atual

54 termos.
